Design direction options

Four takes on "fresh, AI-native" for ICP SKILLS. Open each in turn and compare — each file is self-contained.

Option 1

Neural Grid

Deep space background, subtle neural-mesh grid, electric cyan + magenta accents. Monospace display type. Feels like an agent's substrate.

 Option 2

Terminal Native

Pure black, phosphor-green, mono-everywhere. Treats the site like a CLI surface — the place agents actually live.

 Option 3

Aurora Mesh

Vivid purple→pink→cyan mesh gradient, glassmorphism cards, rounded soft-UI. Modern, fresh, Vercel/Replicate energy.

 Option 4

Quiet Intelligence

Warm paper, one bold accent, serif headings, lots of whitespace. Trustworthy & considered — Anthropic docs mood.
